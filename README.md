# Учебен проект `TutorMySQL`, подготовка за `StreetLightsMasterHtml`

Има бакенд за работа с `MySQL` и `ESP32` концентратори в трафопостовете на уличо осветление от проект `StreetLightsHostESP32`.

Фронтенд от `html` и `js` за диагностика и управление на осветлеието в населените места.

## Инсталиране и стартиране на бакенда

Инсталиране:

```bash
npm install mysql
npm install express
```

Стартиране:

```bash
node --watch server.mjs
```

или:

```bash
npm start
```
